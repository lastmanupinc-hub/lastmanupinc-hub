## What I'm building

**[Trust Fabric](https://trustfabric.ai)** — audits a fintech codebase against the compliance frameworks that actually apply to it (KYC, BSA/AML, PCI-DSS, MTL/MSB, FFIEC, PSD2 SCA, SOC 2), writes the remediation, and issues a verifiable Trust Passport.

**[PAID](https://paid.trustfabric.ai)** — multi-rail payments. Cards, ACH and USDC on one checkout, with every financial event signed and hash-chained so reconciliation takes seconds instead of days.

**[Iliad](https://iliad.trustfabric.ai)** — deterministic artifact generation. Point it at a repo and it produces the context an AI agent needs to work on it. Same input, same output, every time.

**Last Man Up Inc** — a Northwest Indiana veterans organization building a 90-day program for veterans with PTSD, pilot cohort departing September 2027. It's an Indiana nonprofit corporation; the 501(c)(19) application is pending and contributions are not currently tax-deductible.

Last Man Up Inc owns the technology companies above. That's deliberate — a veterans program funded entirely by grants ends when the grant does.
